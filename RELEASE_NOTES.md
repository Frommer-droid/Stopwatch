# История изменений (Release Notes)

## Версия 1.2.0 (2026-09-18)

*Независимые настраиваемые пороги предупреждений Hold.*

### ✨ Новые возможности

- Независимые пороги одновременного Hold (**3:30**) и общего Hold (**3:40**): каждый настраивается в формате ММ:СС и отключается значением `0:00`.
- Пороги сохраняются в локальном `settings.json` и применяются сразу без перезапуска.

### 🛠 Улучшения

- Обложка `README.md` и `README.en.md`: иконка `logo.ico`, центрированный заголовок и ссылка на последний релиз.
- Удален неиспользуемый `Вернись.mp3` из исходников и сборки.
- Тесты изолированы от локального `settings.json` и стабильно проверяют оба порога.

## Версия 1.1.1 (2026-09-16)

*Уточнён порог предупреждения по суммарному Hold и подготовлен безопасный публичный релиз.*

### 🛠 Улучшения

- Предупреждение по сумме Hold срабатывает на **3:40** вместо 5:30.
- Сборка больше не включает локальный `settings.json` с положением окна и координатами Softphone.
- Добавлена проверка происхождения нативных бинарных файлов во время сборки PyInstaller.
- Добавлен воспроизводимый сценарий создания Windows installer из проверенной папки сборки.

## Версия 1.1.0 (2026-08-20)

*Добавлена опция统一 звука для всех сигналов.*

### ✨ Новые возможности

- Настройка **«Один звук (signal.mp3)»** — при включении все звуковые сигналы (начало/конец Hold, предупреждения, начало/конец звонка) воспроизводят единый файл `signal.mp3`.

### 🛠 Улучшения

- Добавлен `signal.mp3` в обязательные файлы сборки.

## Версия 1.0.1 (2026-01-28)

*Технический релиз с исправлением линтера и обновлением конфигурации.*

### 🛠 Улучшения

- Исправлена ошибка линтера Ruff (неиспользуемый импорт).
- Обновлен `.gitignore` (добавлены правила для служебных файлов).

## Версия 1.0.0 (2025-12-07)

*Первый выпуск таймера и секундомера с горячими клавишами и оповещениями.*

### ✨ Новые возможности

- Таймер обратного отсчета с визуальным и звуковым оповещением.
- Секундомер с возможностью установки будильника.
- Глобальные горячие клавиши (F3 - старт/стоп, F8 - сброс).
- Автоматизация кликов по завершении таймера (интеграция с Naumen SoftPhone).
- Закрепление окна поверх всех окон.
- Масштабируемый интерфейс (Normal, Small, Large).
- Сворачивание в системный трей.

### 🛠 Улучшения

- Настройки сохраняются в `settings.json`.
- Звуковые уведомления для всех событий (Старт, Стоп, Таймер, Секундомер).
- Возможность выбора координат клика через GUI.
