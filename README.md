<h1 align="center">Stopwatch</h1>

<p align="center"><strong>Таймер звонка и Hold, который остаётся поверх всех окон.</strong></p>

<p align="center"><a href="README.en.md">English</a> · <a href="https://github.com/Frommer-droid/Stopwatch/releases/latest">Скачать последнюю версию</a></p>

Stopwatch для Windows показывает текущий Hold, сумму Hold и общее время разговора, оставаясь поверх других окон.

## Возможности

- Управление звонком клавишей **Ё** и Hold клавишей **Insert**; сами символ и действие Insert при этом не передаются другим приложениям.
- Три счётчика: текущий Hold, его сумма за звонок и общее время звонка.
- Независимые предупреждения одновременного и общего Hold: по умолчанию 3:30 и 3:40, каждый порог настраивается в формате ММ:СС и может быть отключён значением `0:00`; визуальное мигание и звук можно отключить в настройках.
- Клик в настроенную точку окна Softphone при переключении Hold.
- Режим поверх всех окон, три размера интерфейса и сворачивание в системный трей.

## Установка

Готовые сборки публикуются на странице [последнего релиза](https://github.com/Frommer-droid/Stopwatch/releases/latest). Скачайте installer, установите приложение и запустите `Stopwatch`.

## Использование

Нажмите **Ё**, чтобы начать звонок; повторное нажатие завершает его и сбрасывает счётчики. Во время активного звонка нажимайте **Insert**, чтобы начать или завершить Hold. Левый и правый счётчики также поддерживают управление мышью, а правый клик по ним сбрасывает все значения.

Двойной клик по правому счётчику открывает общие настройки, включая независимые пороги одновременного и общего Hold. Двойной клик по ручке окна открывает настройку цели Softphone и координат клика. `settings.json` создаётся рядом с приложением при сохранении настроек и хранит только локальные параметры.

## Требования и запуск из исходников

Приложение рассчитано на Windows 10/11. Для запуска из исходников нужны Python 3.12+ и зависимости из `requirements.txt`.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\Start-Stopwatch.ps1
```

Проверка логики горячих клавиш и состояния звонка:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```
